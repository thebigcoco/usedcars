6. 買幾年的中古車最划算？

假設買進後開 3 年再賣，這 3 年的折價佔買進價格的比例（越低越划算）。以 8891 市場各車齡折價% 中位數計算，只用每個車齡至少 5 台的資料；綠底為各車系最低。

  • 結論（2026-11 資料）：A-Class 買 3~5 年、C-Class 買約 2 年的車最划算。新車開 3 年要虧掉買價約 34~37%；A-Class 3~4 年車開 3 年約虧 19~21%，C-Class 2 年車約虧 16%。
  • A-Class：同一代 W177 賣到現在，折價曲線平順，3~5 年車都在 19~21%。
  • C-Class：2021 → 2022 年 W205 換代成 W206，3~4 年以上的車容易碰上換代後的價格斷層（開 3 年虧 32~45%），所以 2 年車最划算。
  • 加上認證車：Mercedes-Benz Select 認證車平均比同里程行情貴約 8~12%，會吃掉買 2~3 年車省下的折價；除非很在意原廠認證保固，否則同車齡的一般市場車較划算。
  • 只計算折價，未含保養維修成本：車齡越大維修費越高，5 年以上的實際持有成本會比表上更高。新車原廠保固通常為 3 年，3 年左右的車搭配原廠認證保固特別實用。新車價用牌價、市場價用刊登價，部分車齡樣本僅 5~10 台，以未來 3 年會跟現在的折價曲線一樣為前提，數字當大方向參考。

計算方式與說明

・市場行情：擷取 8891中古車 賓士 A、C 系列全部在售刊登（1616 筆），只取「A-Class」（掀背）與「C-Class Sedan」，依車型（A180 / AMG A35 / C200 / AMG C43…）分組，再 依「年份產」對應認證車出廠年份分組。已排除：標題含「原廠認證」等字樣的刊登（1 筆，多為認證車在 8891 重複刊登，避免拿認證車和自己比）、「電洽」、以及低於該組中位數 40% 的誘餌價。8891 為刊登價（非成交價），實際成交通常再低一些，也可能有同車重複刊登。

・vs 同年中位數 = Select 售價 ÷ 同車款同年份市場中位數 − 1。同里程行情 = 同車款同年份中、里程最接近的 7 台市場車售價中位數（滑鼠移到數字上看里程範圍）；同里程行情價差 = Select 售價 − 同里程行情（萬元，比較表為該組平均）；vs 同里程行情 = Select 售價 ÷ 同里程行情 − 1。正值＝Select 較貴。紅底 ≥ +5%，綠底 ≤ −5%。

・折價 = 新車售價 − Select 售價；折價% = 折價 ÷ 新車售價。車齡 以領牌年月起算，顯示至小數一位；一年折價% = 折價% ÷ 整數車齡（四捨五入，最少 1 年）；年複合折價% = 1 − (售價/新車價)^(1/整數車齡)。

・新車售價：取自 Yahoo汽車 各年式牌價。10~12 月出廠的車視為次年式；A180 2020~2023 年式以「運動版」計（另有較便宜的摘星版）。滑鼠移到數字看依據。

・同車型內的版本與選配（如 AMG Line、摘星版、進化版）、車況未納入行情比較。Mercedes-Benz Select 網站未提供銷售狀態，「狀態」欄留空。8891 上 2024~2025 年的 C-Class 刊登很少（多數組別 1~2 台），這些組別只列同年中位數、不計算同里程行情，參考性較低。
